In this projet we are going to use Zernio, by which we can connect and automate social media accounts.

We can use it manange, schedule, publish and automate content across multiple social media platforms.
It supports all populare social media platfomrs including Instgram, LinkedIn, X, Tik Tok, Youtube, Facebook, Reddit and many more.
